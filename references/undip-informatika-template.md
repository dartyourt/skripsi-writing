# UNDIP Informatika Thesis Template Rules

## Source and status

Sumber kerja: template yang diberikan pengguna, `02. Template dan Format Penulisan Skripsi V. 2024.10-2.docx`. Ini ringkasan operasional, bukan pengganti pedoman resmi terbaru. Catat versi sumber saat audit dan tandai perbedaan dengan pedoman pembimbing.

## Front matter

- Cover: perhatikan pemenggalan judul, spasi, dan ukuran logo sesuai template.
- Halaman pengesahan: tanggal lulus tetap kosong sampai ditetapkan pihak berwenang.
- Kata pengantar: bahasa sopan, baku, tidak berlebihan, dan tidak menceritakan isi skripsi sebagai pengganti abstrak.
- Abstrak Indonesia: satu paragraf, satu spasi, tanpa indentasi baris pertama, maksimal 300 kata; mencakup WHY, WHAT, HOW, dan CONCLUSION.
- Abstract: terjemahan bermakna, bukan kata-per-kata; satu spasi, maksimal 300 kata, dan tidak otomatis italic karena berbahasa Inggris.
- Kata kunci/keywords harus konsisten dengan isi dan istilah yang digunakan.

## Headings and contents

- Isi utama menggunakan spasi 1,5 menurut contoh template.
- Kedalaman terdalam yang diperkenankan adalah level 4 (`1.1.1.1`); jangan membuat level 5.
- Daftar isi dibuat dengan Table of Contents/field Word.
- Daftar tabel dan daftar gambar dibuat dengan Table of Figures/field Word.
- Jangan mengetik nomor halaman field secara manual sebagai klaim final.
- Jika heading berubah, field mungkin perlu diperbarui di Word/LibreOffice.

## Paragraphs and lists

- Paragraf isi memiliki satu ide pokok.
- Contoh template menggunakan space before 12 pt dan after 0 pt untuk subbab; verifikasi style aktual dokumen, jangan menimpa semua style berdasarkan asumsi.
- Pemerian tidak menggunakan bullet; gunakan nomor atau huruf.
- Kepala pemerian harus tetap bersama isi pemerian.
- Jika setiap poin membutuhkan penjelasan panjang, pertimbangkan subbab, bukan daftar yang memanjang.

## Tables, figures, equations, and code

- Setiap tabel, gambar, flowchart, bagan, atau komponen harus disebut oleh paragraf sebelum/di sekitarnya.
- Caption dan nomor mengikuti bab serta urutan kemunculan.
- Tabel umumnya satu spasi, tidak melewati margin, dan header diulang bila bersambung.
- Jika tabel sangat panjang, pertimbangkan lampiran.
- Persamaan rata kiri; semua simbol dijelaskan dalam keterangan.
- Source code ditampilkan dalam tabel 2 baris 1 kolom, Courier New 10 pt, garis tidak melewati margin.
- Template menyatakan source code tidak memerlukan caption dan daftar source code di bagian depan; tandai konflik bila pedoman terbaru berbeda.
- Gambar tidak diberi garis tepi, tidak melewati margin, dan teks di dalam gambar tetap terbaca.

## References

- Template mengarahkan penggunaan APA Seventh Edition atau format setara.
- Buat daftar pustaka secara otomatis melalui References/Citations & Bibliography jika memungkinkan.
- Perubahan manual harus dicatat bila memengaruhi field atau style.

## Red instructional content

Template dapat berisi tabel merah atau teks petunjuk. Hapus hanya setelah audit memastikan bagian itu instruksi template, bukan data atau isi skripsi pengguna.

## Audit checklist

- [ ] Versi template dicatat.
- [ ] Abstrak dan abstract memenuhi batas.
- [ ] Heading maksimal level 4.
- [ ] TOC/figures/tables berupa field atau status keterbatasan dicatat.
- [ ] Semua tabel/gambar disebut dalam teks.
- [ ] Penomoran mengikuti bab dan kemunculan.
- [ ] Pemerian tidak memakai bullet.
- [ ] Source code, persamaan, tabel, dan gambar mempertahankan style.
- [ ] Daftar pustaka dan sitasi konsisten.
- [ ] Teks petunjuk tidak terhapus sebelum diklasifikasi.
