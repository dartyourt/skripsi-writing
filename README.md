# Skripsi Writing — UNDIP Informatika

Skill lokal untuk audit dan revisi skripsi S1 Informatika Universitas Diponegoro dalam format DOCX.

## Isi

- `SKILL.md` — audit → proposal Markdown → approval → edit DOCX konservatif → verifikasi.
- `references/undip-informatika-2024.md` — ringkasan template UNDIP Informatika.
- `references/eyd-edisi-kelima.md` — pedoman kerja EYD Edisi Kelima dan tautan sumber https://eyd.netlify.app/.
- `references/README.md` — provenance dan privasi PDF.
- `templates/proposal-edit.md` — template proposal perubahan.

## Status penggunaan

Folder ini sudah dapat digunakan sebagai skill lokal setelah disalin ke direktori skill Hermes. Loader sesi yang sedang berjalan mungkin baru melihat skill pada sesi baru.

## Instalasi privat

Salin folder ke direktori skill lokal, atau gunakan ZIP/private repository. Untuk teman, GitHub private dengan akses collaborator menjaga repo tidak terbuka untuk umum.

## Distribusi GitHub public

GitHub public memungkinkan siapa pun membaca dan menginstal skill tanpa akses khusus. Publikasikan hanya file aturan umum, referensi tautan, template kosong, dan dokumentasi. Jangan masukkan DOCX skripsi, PDF jurnal berhak cipta, data penelitian, identitas mahasiswa, audit, atau proposal pengguna.

ClawHub tidak digunakan untuk proyek ini.

## Batasan

Preservasi DOCX perlu health check dan pemeriksaan visual dengan Word/LibreOffice untuk klaim layout. Skill tidak menjamin kebenaran metodologi atau pedoman UNDIP terbaru tanpa sumber yang diberikan.
